\chapter{Hướng Dẫn Cài Đặt và Triển Khai}
\label{app:installation}

\section{Yêu cầu hệ thống}

\begin{itemize}
  \item Docker 24.x và Docker Compose 2.x
  \item Python 3.11+ (cho development)
  \item Node.js 20+ (cho Chrome Extension)
  \item GPU NVIDIA với CUDA 12.x (tùy chọn, cho training)
\end{itemize}

\section{Cài đặt môi trường Development}

\begin{lstlisting}[style=bashstyle, caption={Cài đặt development environment}]
# 1. Clone repository
git clone https://github.com/[username]/vietnamese-emotion-detection
cd vietnamese-emotion-detection
# 2. Tao file moi truong (.env)
cp .env.example .env
# Chinh sua cac bien moi truong trong .env

# 3. Download PhoBERT ONNX model
python scripts/download_model.py --quantize int8

# 4. Khoi dong tat ca services
docker compose up -d

# 5. Kiem tra trang thai
docker compose ps

# 6. Xem logs
docker compose logs -f inference-engine

# 7. Test API
curl -X POST http://localhost:8000/api/v1/text/analyze \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $API_TOKEN" \
  -d '{"text": "toi thay minh khong co gia tri gi ca"}'
\end{lstlisting}

\begin{notebox}
Bổ sung hướng dẫn chi tiết: (1) cách chạy fine-tuning PhoBERT trên Google Colab (link notebook); (2) cách cài Chrome Extension vào Chrome; (3) cách kết nối với Jitsi Meet test instance; (4) troubleshooting các lỗi thường gặp.
\end{notebox}

\chapter{Mẫu Thông Báo Consent cho Người Dùng}
\label{app:consent}

\begin{mdframed}[linecolor=accentblue, linewidth=1.5pt, topline=true]
\textbf{\large THÔNG BÁO VỀ PHÂN TÍCH CẢM XÚC TỰ ĐỘNG}

\vspace{0.5em}

Phiên họp/học này sử dụng hệ thống AI để phân tích văn bản hội thoại nhằm hỗ trợ nhận biết sớm dấu hiệu căng thẳng tâm lý.

\vspace{0.5em}
\textbf{Hệ thống CHỈ phân tích văn bản transcript -- KHÔNG thu thập audio, video hay khuôn mặt của bạn.}

\vspace{0.5em}
\textbf{Đây là công cụ hỗ trợ, KHÔNG phải chẩn đoán y tế. Kết quả chỉ được chia sẻ với người giám sát được ủy quyền.}

\vspace{0.5em}
Bạn có thể opt-out bất kỳ lúc nào trong \textit{Settings > Quản lý Consent}. Khi opt-out, toàn bộ dữ liệu của bạn sẽ được xóa trong vòng 48 giờ.

\vspace{1em}
\begin{center}
\large $\square$ \textbf{Tôi đã đọc và đồng ý với các điều khoản trên}
\end{center}
\end{mdframed}
